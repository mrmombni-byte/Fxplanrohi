FREE PUBLISHING OPTION (GitHub Pages)
1. Create a GitHub account at https://github.com/ (free).
2. Create a new public repository, e.g. fxplanrohi-site.
3. Upload index.html, style.css, and script.js from this folder to the repository root.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for GitHub Pages to publish. The free address will usually look like https://YOUR-USERNAME.github.io/fxplanrohi-site/.

A custom .com domain is optional and costs money. Online payment, especially Iranian rial and automatic USDT/BEP20 confirmation, needs separate provider setup and may have eligibility, legal, and transaction fees. Never share account passwords or seed phrases.
